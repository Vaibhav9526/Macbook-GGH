### Changed

- A joined server can now show you agents on providers that your Jargon does not know yet. The
  agent stays in your list and you can chat with it. Its provider and model choices are disabled
  and show "Update Jargon to use" and the provider name.
- New providers no longer need a new Team API version. Older Jargon versions do not see agents
  on providers that they do not know.
